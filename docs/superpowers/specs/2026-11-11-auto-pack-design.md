# Windows 文件传输打包工具设计

状态：按用户对方案的调整实施，输出目录和密码均为持久设置。

## 目标

创建一个运行在 Windows 上的桌面应用，将用户选择的一组文件复制到一个自动命名的文件夹中，再生成每卷最大 700M 的加密压缩包，便于传输。用户明确要求文件夹名包含“文件传输”、当前日期及序号。

## 实现方案

- 推荐：C# / WinForms 桌面界面，调用随程序提供的 7-Zip 引擎，生成 7z 分卷，启用 AES-256 和文件名加密。原生文件选择体验，运行时无需安装 Python，也无需用户单独安装 7-Zip。
- 替代：相同界面生成 AES 加密 ZIP，部分工具兼容性更好，但不能采用 7z 的文件名加密方式；仍需支持 AES 的解压工具。
- 不选：仅提供脚本，用户操作、进度及错误提示不如桌面应用直接。

实现者负责选择受支持的 .NET 版本和固定版本的官方压缩引擎，提供 Windows x64 自包含发布流程，并附上第三方许可证及来源。首版不提供 macOS/Linux 界面和安装程序。

## 界面和流程

单窗口中文界面，包含：添加文件、移除所选、清空、文件列表、设置入口、当前输出位置、密码已配置状态、任务命名预览、开始、取消、进度、结果提示、打开输出目录。输出目录和密码为持久设置，不需要每次打包时重新选择或输入。

```text
文件传输打包                       [设置]
[添加文件] [移除所选] [清空]
文件名                         大小
合同.pdf                       ...
资料.xlsx                      ...
输出位置：D:\文件传输
加密密码：已配置
任务名称：文件传输-2026-11-11-001
格式：7z / AES-256 / 文件名加密 / 每卷 700 MiB
[开始打包] [取消]     进度与状态
```

首次启动时打开设置窗口，配置输出目录和加密密码，密码需输入两次且相同、非空。保存后，后续启动自动读取设置，日常只需选择文件并开始。设置窗口可随时修改输出目录或密码；修改密码时重新确认，保存新密码前不覆盖现有密码。已保存密码不回填到可见文本字段，以“已配置”状态显示，留空表示保持原密码。

设置按当前 Windows 用户保存至 `%LOCALAPPDATA%\AutoPack\settings.json`，输出目录以普通配置值保存，密码经 Windows DPAPI 的 `CurrentUser` 范围加密后保存为 Base64 密文。设置采用临时文件加原子替换方式写入，写入失败时保留原配置并显示错误。换电脑或 Windows 用户后若无法解密，要求在设置中重新配置密码，不静默覆盖原密文。

每次开始仍检查输出目录是否存在、是否可写；不存在时尝试创建，磁盘不可用或无权限时提示打开设置修正。任务开始时固定目录和密码快照。复制、压缩和校验在后台进行；执行期间禁止修改任务输入和设置。取消后终止本任务的子进程，并等待退出后清理本任务的未完成产物。

## 文件和命名

- “当前日期”采用运行应用的 Windows 本地日期，在任务开始时固定，格式为 `yyyy-MM-dd`。
- 序号在所选输出目录内、按日期递增，从 `001` 开始；扫描该日期已有任务文件夹及分卷名称后取最大序号加一；超过 999 时继续增长。
- 创建任务目录时防止并发覆盖，若被另一实例抢占则重新分配序号；绝不覆盖既有文件。
- 原文件只复制，不移动。整理文件夹和压缩分卷都保留在输出目录，压缩包包含这个顶层整理文件夹。
- 以 Windows 大小写不敏感规则检查同名源文件；发生冲突时列出冲突并要求先移除，绝不静默覆盖或改名。
- 首版只选择普通文件，不递归添加文件夹；拒绝重复路径、符号链接和重解析点，避免打包范围超出用户选择。
- 选择空文件、中文名、空格和 Unicode 文件名均应支持。压缩仅处理本次整理目录，不扫描输出目录中的其他文件。

示例输出：

```text
输出目录/
  文件传输-2026-11-11-001/
    合同.pdf
    资料.xlsx
  文件传输-2026-11-11-001.7z.001
  文件传输-2026-11-11-001.7z.002
```

700M 默认解释为 700 MiB，即 734003200 字节。最后一卷可以更小，小文件也使用 `.7z.001` 命名。全部分卷放在同一目录，从 `.001` 开始用支持加密 7z 的工具解压；不承诺 Windows 内置解压支持。

## 加密、校验与异常

- 必须配置密码，同时加密内容和文件名；记住密码供后续任务自动使用。配置文件仅保存经 Windows DPAPI 保护的密码密文，不保存明文；日志和任务结果不输出密码或密文。
- 优先通过压缩引擎标准输入交互传递密码，避免密码出现在进程命令行。应通过实际测试验证该引擎版本的交互协议，不以回退到明文命令行解决协议问题。
- 压缩完成后以同一密码执行压缩包完整性测试，检查分卷存在且大小不超过限制；只有这些步骤通过才显示成功。
- 文件不存在、读取失败、权限不足、磁盘空间不足、引擎缺失、压缩失败和校验失败均显示可理解的中文提示。
- 开始前检查源文件和输出位置。读取过程中源文件改变时停止并提示用户重试；不把不稳定输入报告为成功。
- 失败或取消时仅清理本任务创建的分卷和整理目录；不得删除用户源文件或既有任务。清理失败时明确提示残留路径。
- 窗口关闭时，运行中的任务需要先取消并等待子进程退出，不留下后台压缩进程。
- 整理目录是用户要求保留的普通文件副本，只有压缩分卷经过加密；界面结果和 README 明确说明。
