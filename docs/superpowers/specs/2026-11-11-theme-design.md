# 浅色与深色主题设计

状态：用户已确认，按本方案实施。

## 目标与范围

按用户要求，为现有 Windows WinForms 应用提供浅色和深色主题，覆盖主窗口和设置窗口，保持现有布局和打包流程。

## 方案

采用统一主题配色和控件样式入口，两个窗口共用，避免分散维护颜色。仅依赖 Windows 原生主题无法覆盖当前自定义的背景、提示文字和表格；逐窗口维护两套颜色容易产生差异。沿用现有 .NET 10 / WinForms 技术栈，不增加 UI 框架。

## 用户体验

- 设置窗口增加“界面主题”下拉选项，提供“浅色”和“深色”。
- 在设置窗口切换时预览；点击“保存设置”后主窗口同步并持久保存，取消则保持原选择。
- 首次启动及没有主题字段的旧配置默认浅色，沿用当前外观。
- 重新启动恢复已保存主题。修改主题时密码可留空，继续沿用已有密码。

```text
打包设置
输出目录  [目录路径                         ] [浏览…]
界面主题  [浅色 / 深色                           ▾]
新密码    [留空表示保持原密码                    ]
确认密码  [                                      ]
          □ 显示输入的密码
          提示说明
                              [取消] [保存设置]
```

## 实现约束

- 统一定义窗口背景、内容背景、正文、辅助文字、边框、按钮交互状态、强调色及表格选中颜色，覆盖空列表和新添加行。
- 覆盖输入框、下拉框、复选框、按钮、说明区及文件列表表头；适配禁用状态。窗口标题栏及系统控件使用可用的 Windows / WinForms 主题支持。
- 主题保存到现有 settings.json，兼容旧配置；密码仍经现有 DPAPI 流程保存，保留原子写入和失败保护。
- 保持窗口缩放和确认密码显隐行为正常。不增加跟随系统模式。
- 文件选择器、目录选择器及系统消息框保留 Windows 提供的外观。

## 后续调整：统一按钮

按用户后续要求，所有应用内按钮统一为 96 DPI 下 128 × 36 的基准尺寸，随窗口 DPI 缩放；由 `ThemedButton` 集中定义。浅色/深色主题各使用同一套填充、文字、边框以及悬停、按下和禁用配色，取消开始打包及保存设置的单独强调色。浏览按钮沿用同样尺寸，输出目录输入框在该行垂直居中。

## 验证

验证主题保存与恢复、旧配置默认值、无效主题值及写入失败保护，运行现有测试和 Windows 交叉编译。当前开发环境为 macOS，Windows 实机上两个主题的对比度、控件状态、标题栏和 DPI 显示需要单独验证，不能以交叉编译代替。
