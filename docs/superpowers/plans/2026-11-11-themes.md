# 浅色与深色主题实施计划

> 在当前会话按任务执行，沿用项目不代用户提交或推送的约定。

**Goal:** 为主窗口和设置窗口提供可保存、预览和恢复的浅色/深色主题。

**Architecture:** 核心配置增加向后兼容的 Theme 字段；WinForms 统一配色管理器覆盖控件，设置窗口只预览自身，保存成功后主窗口应用。

**Tech Stack:** .NET 10 / C# / WinForms。

**Spec:** `docs/superpowers/specs/2026-11-11-theme-design.md`

## 约束与审查重点

- 原配置缺少主题时默认浅色，不能要求重新输入密码。
- 无效主题不能写入或静默损坏原配置。
- 取消预览或保存失败时主窗口保持原主题。
- 文件列表新增行、选中行及按钮禁用状态采用对应主题。
- 设置新增一行后保留 DPI 缩放和密码显隐布局；标题栏在句柄重建后仍正确。
- 系统文件选择器和提示框保留 Windows 外观；macOS 交叉编译不代表 Windows 界面实测。
