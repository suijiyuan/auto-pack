# AutoPack Implementation Plan

> **For agentic workers:** Implement this plan task-by-task in the current session. Steps use checkbox syntax for tracking.

**Goal:** 创建 Windows 文件整理和加密分卷工具，输出目录和密码配置一次即可重复使用。

**Architecture:** WinForms 主窗口负责文件选择、设置和状态。独立核心库负责命名、复制、压缩、校验和清理；设置通过 Windows DPAPI 加密后原子保存。官方固定版本 7-Zip 随发布包提供，密码经标准输入传递。

**Tech Stack:** C# / .NET 10 / WinForms / Windows DPAPI / 7-Zip 26.06。

**Spec:** `docs/superpowers/specs/2026-11-11-auto-pack-design.md`

## Global Constraints

- 默认分卷 734003200 字节；7z AES-256 内容和文件名加密。
- 文件夹命名 `文件传输-yyyyMMdd-001`，序号按输出目录和日期递增。
- 原文件只复制，不移动；不能覆盖现有输出。
- 输出目录和密码持久保存，配置和日志无明文密码。
- 运行期间锁定设置；取消和失败只清理本任务创建的产物。
- 当前环境为 macOS；构建 Windows 发布包，区分跨平台验证和 Windows 专属验证。

## Review Focus

- 不同路径同名文件（包括仅大小写不同）必须在复制前拒绝。
- 输出目录不可用、配置损坏、DPAPI 解密失败不能静默重置配置。
- 进程取消后必须等待退出，随后才能删除分卷。
- 输出目录内其他任务及源文件不得被失败清理删除。
- 中文及特殊字符密码通过标准输入完整传递，不出现在命令行。

## Files and Interfaces

- `src/AutoPack.Core/SettingsStore.cs`: `AppSettings`、`ISecretProtector`、`SettingsStore.Load/Save`。
- `src/AutoPack.Core/WindowsSecretProtector.cs`: DPAPI 用户范围保护。
- `src/AutoPack.Core/PackService.cs`: `PackRequest`、`PackProgress`、`PackResult`、`PackService.RunAsync`。
- `src/AutoPack.Core/SevenZipRunner.cs`: 压缩进程、标准输入密码和取消生命周期。
- `src/AutoPack.WinForms/Program.cs`、`MainForm.cs`、`SettingsForm.cs`: 中文桌面应用。
- `tests/AutoPack.Tests/Program.cs`: 无外部框架的可执行测试，失败返回非零。
- `scripts/publish.ps1`: 固定引擎校验、自包含 Windows x64 发布和压缩发布包。
- `.github/workflows/ci.yml`: `master` 分支推送和面向 `master` 的 PR，执行 Windows 构建、DPAPI 测试和引擎集成验证。
- `.github/workflows/release.yml`: 推送 `v*` 标签时执行测试、打包、生成 SHA256 校验文件，上传 Actions 制品并创建附带 ZIP 和校验文件的 GitHub Release。
